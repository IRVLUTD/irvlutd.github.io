04 / INTERPRETATION

Experiment details

  1. Success rate: LIBERO-confirmed successes ÷ 100 planned episodes per model and reasoning configuration; stopped, incomplete, error, and missing episodes count as failures.
  2. Episode limits: 80 model calls, 900 simulator steps (45 seconds at 20 Hz).
  3. Reported metrics: outcome, simulator steps, API calls, token usage, API latency, and cost per episode.
  4. Observation history: two most recent observations, each with agent-view and wrist-camera images.
  5. Output limit: 3,072 tokens per call, including reasoning.
